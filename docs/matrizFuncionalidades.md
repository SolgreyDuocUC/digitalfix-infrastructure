# Matriz de Funcionalidades — DigitalFix

**Asignatura:** DSY1107 Desarrollo Cloud Native I — Duoc UC
**Proyecto:** DigitalFix, plataforma de órdenes de trabajo para mantenimiento eléctrico en terreno
**Fecha de corte:** 18-10-2026

**Arquitectura evaluada:**
- Flujo de una petición: Angular (MSAL) → BFF Gateway (validación del JWT de Entra ID) → microservicios de dominio (Spring Boot 4 + Oracle Autonomous).
- Mensajería asíncrona: RabbitMQ, administrado por ms-admin-queues y consumido por ms-notify.
- Orquestación: Docker Compose centralizado en `digitalfix-infrastructure`.

**Estados:**
- **Implementada:** funciona y se puede verificar con la evidencia indicada.
- **Parcial:** el código existe, pero falta configuración o un caso.
- **No Implementada:** pendiente; en Observaciones se indica cómo debe quedar.
